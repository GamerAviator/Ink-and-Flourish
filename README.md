# Ink & Flourish

A tablet-friendly cursive practice app with daily lessons, tracing feedback, animated lowercase stroke guides, personal progress, and a signature workshop.

## Install on a tablet

Once GitHub Pages is enabled, open https://GamerAviator.github.io/Ink-and-Flourish/ on the tablet.

- iPad/iPhone: Open in Safari, tap Share, then Add to Home Screen and Add.
- Android tablet: Open in Chrome, tap Install app in the app, or the browser menu's Install app / Add to Home screen option.

Open it online once to prepare the offline files. Handwriting and progress are saved only in this device's browser or installed app, with separate learner profiles. They do not synchronize between devices. Progress from the original ChatGPT-hosted site does not transfer automatically to this GitHub Pages address.

## Enable GitHub Pages

In this repository, open Settings → Pages. Under Build and deployment, select Deploy from a branch, choose main and / (root), and Save. GitHub will publish the app after the Pages build finishes.

## Practice and feedback

Daily practice includes a warmup, review, a new skill, and a challenge with the guide hidden. A daily lesson earns 50 XP once per local calendar day, with streaks, freezes, badges, and targeted review. Tracing feedback measures shape coverage and closeness to the guide; it does not assess readability, stroke order, or stroke direction. A parent can review independent samples. Signature practice is available immediately from Daily journey or My signature, with saved daily completion, a separate signature streak, and a remembered name for each learner. Animated stroke guides cover lowercase letters; capitals are not animated yet.
